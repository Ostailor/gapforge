# Experiment Code Implementation

## Purpose
Constrain Codex/GPT-5.4 implementation work to runnable experiment code without creating fake empirical artifacts.

## When To Use
- Generating workspace code scaffolds.
- Creating Codex tasks for dataset loaders, baselines, metrics, runners, ablations, tests, or smoke debugging.
- Importing implementation patches.

## Inputs
- Workspace ID, protocol, dataset cards, baseline cards, metric definitions, scaffold files, validation commands.

## Outputs
- Code under `experiment_workspaces/{workspace_id}/code/`
- experiment code task pack
- tests/configs/scripts

## Required Artifacts
- `code/pyproject.toml`
- `code/src/`
- `code/tests/`
- `code/configs/`
- `code/scripts/run_smoke.sh`
- task pack with validation commands

## Procedure
1. Scaffold with `gapforge scaffold-experiment-code`.
2. Generate focused Codex code task.
3. Ensure task permits edits only under workspace `code/`.
4. Run or record validation commands.
5. Import code changes only if paths are valid and no fake results are present.

## Validation Checklist
- [ ] Code task has exact files and validation commands.
- [ ] Patch stays under workspace code root.
- [ ] Tests/smoke commands exist.
- [ ] Placeholder data is labeled.
- [ ] No result artifact is generated by hand.

## Failure Modes
- Codex writes outside workspace.
- Codex creates fake metrics to satisfy tests.
- Smoke pass is described as empirical success.

## Examples
```bash
gapforge scaffold-experiment-code --workspace-id WORKSPACE
gapforge experiment-code-task --workspace-id WORKSPACE --type implement_metric
gapforge experiment-code-handoff --task-id TASK
gapforge experiment-code-import --task-id TASK
```

## Evidence Rules
Code is implementation evidence only. Empirical evidence starts at execution records and result artifacts.

## Uncertainty Rules
Missing datasets or baselines become TODOs/blockers, not fabricated code availability.

## Chain-Of-Thought Rule
Store only public reasoning summaries. Do not request or store hidden chain-of-thought.

## No Fake Results
Do not write fake `metrics.json`, fake plots, fake logs, fake benchmark scores, or fake confidence intervals.
