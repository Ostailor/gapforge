# GapForge v2.1.0 Release Notes

GapForge v2.1.0 is the Selected Idea Execution release. It takes the v2 human-accepted idea and turns it into a runnable benchmark smoke workflow with conservative gates around synthetic evidence and low-FPR claims.

## Selected Idea

- Idea ID: `idea-sequential-specificity-benchmark-for-low-fpr-collusion-audits`
- Title: `Sequential specificity benchmark for low-FPR collusion audits`
- Research question: Can a sequential benchmark evaluate collusion monitors at operationally meaningful low false-positive rates?
- Selected project: `v2-1-sequential-specificity-benchmark-for-low-fpr-collusion-audits`

The selected idea is locked. Future v2.1 work should extend this research target rather than silently replacing it with a different idea.

## Smoke Run Status

The selected benchmark smoke path passed with label `synthetic_underpowered_smoke_only`.

The smoke dataset contains synthetic honest, collusive, and ambiguous traces for transcript-visible and action-only observability modes. Honest traces include benign coordination hard negatives that can produce false positives. Collusive traces carry explicit collusion labels. Ambiguous traces remain excluded from main metric claims unless a later protocol opts them in.

The low-FPR audit check reported the smoke run as underpowered. Zero false positives were reported with an upper confidence bound, not as proof of operational specificity.

## Reviewer Blockers

The reviewer panel intentionally keeps the manuscript non-publishable at v2.1.0 maturity:

- Underpowered low-FPR evidence cannot support pilot/main or publication claims.
- Pilot and main sample-size gates still need to be fixed before publishability claims.
- Prior-work recall and related-work matrix evidence still need to be attached before novelty claims.
- Synthetic data limitations remain major if overclaimed.

The v2.1 release gate passes because the smoke path is runnable and honest about its limits, not because those reviewer blockers are resolved.

## What Remains for Pilot/Main

- Expand and audit the honest-agent null distribution.
- Expand collusive-agent alternatives beyond smoke fixtures.
- Preregister alpha levels, stopping rules, and sample-size requirements.
- Run the full baseline suite at pilot scale.
- Resolve low-FPR underpowering before making operational specificity claims.
- Complete prior-work recall and related-work matrix gates.
- Re-run reviewer critique after pilot evidence exists.
- Upgrade the manuscript package only when blockers are addressed.

## Remaining Risks

- Synthetic fixture distributions may miss the behaviors needed for a useful real benchmark.
- Baseline monitors are starting points and may be too simple for scientific comparison.
- Smoke sample sizes are too small for strong low-FPR claims.
- Reviewer blockers remain open by design.
- Novelty and prior-work evidence need deeper pilot/main follow-up.
