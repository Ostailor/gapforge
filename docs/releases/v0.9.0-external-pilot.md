# GapForge v0.9.0 External Pilot Report

Release statement: **v0.9 external pilot passed with an accepted correct refusal; no research direction was accepted**.

The v0.9 pilot topic was `low false-positive collusion detection in LLM multi-agent systems`. The pilot objective was to determine whether GapForge could identify a defensible research direction around low false-positive detection of collusion or covert coordination among LLM-based agents, or refuse honestly when the evidence was not sufficient.

## Refusal Basis

The pilot refused instead of promoting a research direction because:

- live source diagnostics reported degraded arXiv fallback metadata
- source coverage was insufficient for a defensible novelty claim
- required live-literature artifacts remained missing or incomplete
- no candidate direction passed the idea gate
- human review accepted the refusal as the correct outcome

This is a successful v0.9 outcome because v0.9 explicitly accepts either a defensible direction or an evidence-backed refusal. The system did not count fixture-only evidence as empirical success and did not invent a direction.

## Product Failure Assessment

No unresolved product failures were recorded for the accepted pilot outcome.

The `v9-smoke` Makefile target was missing during verification and was added before release verification completed. After that fix, `make v9-smoke` passed and the v9 release gate passed.

## v1 and v0.9.1 Decision

The v9 release gate passed and recommended v1 because the external pilot itself reached an accepted outcome.

The v1 readiness gate generated a report but did not pass because the migration/backward compatibility audit has not passed. This blocks a v1 claim. A v0.9.1 release is not required by a pilot product failure, but if migration remediation is handled as a patch release before v1, that work should be released as v0.9.1.

## Remaining Risks

- The refusal happened before a complete live-literature campaign, prior-work recall assessment, novelty dossier, manuscript draft, or real experiment could support a direction.
- Live sources can degrade, so future pilot reruns need fresh diagnostics and source coverage.
- Human review was operator review; independent domain-expert review remains stronger evidence.
- Migration readiness remains unresolved for v1.
