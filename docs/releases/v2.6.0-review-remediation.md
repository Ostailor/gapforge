# GapForge v2.6.0 Review Remediation Notes

These notes summarize how v2.6 handles the v2.5 drastic review blockers for the selected benchmark manuscript.

## Starting Point

v2.5 completed its release gate as `revise_for_reviews`. The drastic panel reported `fatal_blockers`, with likely decision `reject_likely`.

Fatal blockers from v2.5:

- `missing:related_work_matrix`: no auditable related-work matrix was available for novelty calibration.
- `missing:artifact_package`: no artifact evaluation package was loadable for the manuscript.

v2.6 does not hide those blockers. It records whether they are resolved by loadable artifacts.

## Remediation Result

Both v2.5 fatal blockers are resolved for the selected manuscript.

- Related-work matrix: loaded and repaired from v2.4 related-work matrix state.
- Artifact package: repaired from workspace replication-package evidence and then loaded.

The artifact package remediation also fixed a reproducibility bug: seed `0` is now treated as an explicit recorded seed rather than as a missing value.
