# GapForge v2.4.0 Release Notes

GapForge v2.4.0 is the Related Work Completion and Publication-Readiness Remediation release for the locked selected benchmark:

- Idea ID: `idea-sequential-specificity-benchmark-for-low-fpr-collusion-audits`
- Benchmark ID: `benchmark-sequential-specificity-benchmark-for-low-fpr-collusion-audits`
- Title: `Sequential specificity benchmark for low-FPR collusion audits`

v2.3 completed the synthetic main benchmark but was not publication-ready because required related-work categories had no real attached paper records. v2.4 remediates that blocker with executable search evidence, curated real paper attachments, reading evidence, closest-prior-work comparison, softened positioning, manuscript revision, and a reviewer rerun.
