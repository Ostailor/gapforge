# GapForge v0.7.0 Release Notes

GapForge v0.7 is the real benchmark execution and replication upgrade. It extends the v0.6 experiment workspace layer with explicit benchmark records, dataset download consent, compute/job abstractions, sweeps, benchmark result tables, error analysis, comparison reports, low-FPR power checks, and replication packages.

GapForge still must not fabricate benchmark results. Fixture canaries validate plumbing. Real/local public benchmark canaries validate the benchmark-and-replication workflow for a small public dataset. They do not prove broad benchmark performance, SOTA status, GPU/cluster readiness, or independent replication.

## What Changed

- Added benchmark registry records, tasks, suites, cards, readiness checks, and fixture labeling.
- Added external dataset download planning, cache management, explicit consent records, license/terms warnings, manual-download handling, and download hashes.
- Added compute environment checks for local, Docker, GPU-local, Slurm, and custom modes without requiring GPU, Docker, Slurm, or network in CI.
- Added job runner and scheduler abstractions with local execution, queue persistence, cancellation, and unavailable Docker/Slurm reporting.
- Added experiment sweeps, ablation plans, and seed plans with controlled manifest generation.
- Added a normalized result database, result aggregation, CSV export, and smoke/pilot/main separation.
- Added prediction-backed error analysis and slice analysis.
- Added benchmark comparison and leaderboard reports with missing-baseline, run-type, internal/external source, and anti-SOTA guardrails.
- Added low-FPR power planner v2 for required negative sample counts, zero-false-positive upper bounds, alpha target guidance, and underpowered warnings.
- Added replication package export, replication manifests, verification, reproduction runner, and multi-environment reproducibility matrix.
- Added benchmark canaries, v7 release gate, v7 eval fixtures/metrics, dashboard pages, API helpers, docs, and skills.

## How to Run v0.7

Fixture-only benchmark smoke:

```bash
export GAPFORGE_DISABLE_NETWORK=1
gapforge benchmark-canary-run --profile fixture_benchmark_success
gapforge benchmark-canary-run --profile fixture_benchmark_failure
gapforge benchmark-canary-run --profile low_fpr_underpowered_benchmark
gapforge benchmark-canary-run --profile replication_package_canary
gapforge v7-release-gate --write-report --json
```

Opt-in real/local public benchmark canary:

```bash
gapforge benchmark-canary-run --profile local_public_small_benchmark --real --accept-download
gapforge v7-release-gate --write-report --json --claim-real
```

The real/local canary downloads a small public dataset into the ignored GapForge dataset cache after explicit consent. It records benchmark results, prediction artifacts, comparison reports, error analysis, and a replication package. It does not claim benchmark superiority.

## Dataset Consent Status

Dataset consent was recorded for the opt-in public small benchmark canary. Downloaded data is stored under ignored cache paths and must not be committed by default.

The canary uses the public UCI Iris dataset as a small binary detection benchmark. This is sufficient for v0.7 release-gate workflow validation, not for broad benchmark-quality claims.

## Benchmark Results Included

The real/local public benchmark canary produced:

- `metrics.json`: false-positive-rate rows for a required always-negative heuristic baseline and a proposed petal-width threshold detector
- `predictions.json`: artifact-backed predictions used for error analysis
- `benchmark_comparison_*.json/md`: internal comparison report with limitations and no SOTA claim
- `aggregate_results.json/md`: run-type-preserving aggregate results
- `error_analysis_*.json/md`: prediction-backed error analysis

Results are artifact-backed and labeled by run type. Failed fixture paths remain visible. No fake result or SOTA claim is accepted.

## Remaining Risks

- The real benchmark canary is intentionally small and local/public; it is not a broad benchmark suite.
- External benchmark downloads at scale remain opt-in and were not broadly exercised.
- Docker, GPU, Slurm, cluster, and multi-machine execution paths are represented but not validated as available in normal CI.
- Independent replication by another researcher was not completed.
- Low-FPR studies can still be underpowered without enough negative examples.
- External leaderboard verification and SOTA claims remain blocked unless explicitly supported by verified evidence.

## Not Tested

- Large benchmark suites or restricted datasets.
- GPU or cluster execution.
- External leaderboard fetching and verification.
- Independent third-party reproduction.
- Scientific performance claims beyond the small public benchmark workflow canary.
