# GapForge v0.5.0 Release Notes

GapForge v0.5 is the real literature campaign quality upgrade. It moves beyond v0.4.1 workflow canaries by adding live source diagnostics, planned search rounds, paper canonicalization, closest-prior-work recall, human quality review, and a machine-checkable v5 release gate. GapForge is still not an exhaustive autonomous literature reviewer.

## What Changed

- Added live source health diagnostics and live-source readiness reports.
- Added real literature campaign profiles and records.
- Added paper canonicalization v2 with auditable merge decisions.
- Added a search strategy planner with initial, survey, benchmark/dataset, novelty, counterevidence, and adjacent-field rounds.
- Added prior-work recall gates before strong novelty or experiment-ready recommendations.
- Upgraded the campaign controller for real-literature quality flow.
- Added Codex/GPT-5.4 research synthesis task packs after evidence gates pass.
- Added human real-literature quality review, separate from workflow acceptance.
- Added v5 release gate, v5 eval fixtures/metrics, live campaign dashboard/report pages, dry-run planner, APIs, docs, and Codex skills.

## Evidence and Claim Safety

- Fallback/offline records remain visible in coverage but no longer dominate closest-prior-work matching when live source records exist.
- Strong novelty remains blocked without completed prior-work recall.
- Human quality review blocks fake citations, unsupported high-confidence claims, missed obvious prior work, and overclaimed novelty.
- Reports and release notes distinguish workflow acceptance from research-quality acceptance.

## Remaining Risks

- Live source results can be noisy, incomplete, rate-limited, or unavailable.
- Accepted quality campaigns are local release-gate checks, not broad expert-reviewed literature surveys.
- Much evidence is abstract-only unless users ingest and parse PDFs.
- GapForge cannot prove that no prior work was missed.
- Experiment-ready means protocol-ready, not that experiments have been run or results exist.

## Not Tested

- Broad multi-field expert acceptance across multiple independent reviewers.
- Complete full-text coverage for every closest prior-work paper.
- Live literature quality under API outages, rate limits, or source schema changes beyond the diagnostics exercised here.
- Manuscript acceptance, real experiment execution, or claims about empirical results.
