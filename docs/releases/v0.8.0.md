# GapForge v0.8.0 Release Notes

GapForge v0.8 is the manuscript, artifact evaluation, and reviewer-rebuttal upgrade. It turns existing project, literature, experiment, benchmark, result, and replication state into auditable manuscript and submission artifacts without allowing unsupported claims, fake citations, fake results, or premature venue-readiness claims.

The release distinguishes four states:

- **Draft**: sections or package text exists, but review, citation, result, artifact, and traceability gates may still be open.
- **Review-ready**: a review package can be inspected by humans and reviewer simulation, with uncertainty and blockers visible.
- **Submission-ready**: the venue checklist, bibliography, traceability, artifact, anonymization, and unsupported-claim gates pass for the selected venue.
- **Camera-ready**: submission-ready plus fatal reviewer/rebuttal blockers are addressed; open fatal items block camera-ready status.

No real venue submission happened for v0.8, and no venue acceptance is claimed.

## What Changed

- Added durable manuscript project state under `manuscripts/{manuscript_id}/`.
- Added manuscript sections and claim-use records that trace to claims, papers, result artifacts, and other artifacts.
- Added bibliography and citation management with stable keys, BibTeX export, metadata warnings, DOI/arXiv/title dedupe, citation-use records, and fake/unknown citation rejection.
- Added claim-to-manuscript traceability reports and overclaim warnings for unsupported claims, result-without-artifact claims, overstrong novelty, unverified SOTA claims, smoke-as-main-result phrasing, missing citations, and hidden limitations.
- Added manuscript draft generation and rendering from section state.
- Added artifact-backed figure/table generation for result tables, baseline comparisons, metric plots, and failure tables.
- Added venue templates and venue-aware submission checklists.
- Added anonymization/blinding support and identity-leak checks for anonymous venues.
- Added artifact evaluation package v2 with replication-package inclusion, install/run instructions, expected outputs and hashes, hardware/time estimates, checklist checks, badge assessments, and smoke dry-runs.
- Added manuscript reviewer panels and area-chair summaries.
- Added rebuttal and revision workflows that turn objections into required fixes, experiments, searches, citations, and softened claims.
- Added submission package export for review, camera-ready, arXiv, and internal packages.
- Added the v8 release gate.
- Added v8 eval fixtures, dashboard pages, Python API functions, docs, and Codex-readable skills.

## Manuscript and Submission Gate Status

Status: **passed for the v0.8 fixture manuscript workflow**.

`gapforge v8-release-gate --write-report --json` passed locally after a v8 smoke run generated a complete review-package fixture. The gate checked:

- deterministic CI evidence
- v7 release-gate pass or documentation
- manuscript project state
- bibliography
- manuscript draft
- traceability report
- artifact-backed table or figure
- venue checklist
- artifact evaluation package
- manuscript reviewer panel
- rebuttal/revision plan
- submission package export
- unsupported-claim blocking
- fake-citation blocking
- fake-result blocking
- failed/negative experiment acknowledgement
- camera-ready rebuttal blocker handling

The gate emitted a nonblocking warning that the fixture revision plan remains `open`. That warning is intentional: the fixture demonstrates reviewer/rebuttal planning and submission-package gating, while camera-ready status remains blocked until required review fixes are addressed.

This validates the manuscript workflow and gating mechanics. It does not mean a real paper was submitted or accepted.

## Remaining Risks

- The v0.8 release validates manuscript and artifact-evaluation workflow mechanics using fixtures and local artifacts, not a completed real venue submission.
- Independent third-party artifact evaluation was not completed.
- Full LaTeX compilation is not required in CI and was not made a release blocker.
- Reviewer simulation is deterministic and evidence-linked, but it is not a substitute for human peer review.
- Venue templates are generic and conservative; real venue-specific formatting still needs human review.
- Camera-ready status remains blocked when fatal review or rebuttal items are open.

## Not Tested

- Real conference, journal, workshop, or arXiv submission.
- Real venue rebuttal or camera-ready process.
- Independent external artifact-evaluation review.
- Full manuscript PDF production through a required CI LaTeX installation.
- Restricted-data artifact packages.
- Broad real benchmark manuscript claims beyond existing v0.7 workflow validation.
