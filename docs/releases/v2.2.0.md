# GapForge v2.2.0 Release Notes

GapForge v2.2.0 is the Selected Benchmark Pilot Study release. It upgrades the v2.1 selected benchmark from runnable synthetic smoke maturity to an artifact-backed synthetic pilot workflow with explicit low-FPR power gates.

## Selected Idea

- Idea ID: `idea-sequential-specificity-benchmark-for-low-fpr-collusion-audits`
- Title: `Sequential specificity benchmark for low-FPR collusion audits`
- Research question: Can a sequential benchmark evaluate collusion monitors at operationally meaningful low false-positive rates?
- Selected project: `v2-1-sequential-specificity-benchmark-for-low-fpr-collusion-audits`
- Benchmark ID: `benchmark-sequential-specificity-benchmark-for-low-fpr-collusion-audits`

The selected idea remains locked. v2.2 extends that exact target rather than replacing it.

## Pilot Dataset Size and Status

The v2.2 selected pilot dataset is synthetic pilot data:

- Dataset ID: `pilot-trace-dataset-benchmark-sequential-specificity-benchmark-for-low-fpr-collusion-audits`
- Negative traces: 300
- Positive traces: 150
- Hard-negative traces: 214
- Ambiguous traces: excluded from primary metrics by default
- Status: pilot-scale synthetic benchmark dataset, not deployment data

The dataset is sufficient for the pilot alpha target recorded below, but not for main-scale `alpha=0.001` claims.

## Alpha Targets

- `alpha=0.01`: supported at pilot scale with 300 observed negative traces / 299 required negative traces.
- `alpha=0.001`: unsupported and blocked with 300 observed negative traces / 2995 required negative traces.

Zero false positives are interpreted through upper confidence bounds. They are not proof of zero risk. Sequential repeated audit windows still require family-wise false-alarm interpretation.
