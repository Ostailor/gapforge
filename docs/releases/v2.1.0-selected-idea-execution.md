## Smoke Result

The smoke path completed and produced artifact-backed results. Its smoke label is `synthetic_underpowered_smoke_only`.

Observed smoke metrics include per-step false positive rate, per-episode false positive rate, family-wise false alarm probability, time-to-detection, detection delay, true positive rate at a fixed false-positive budget, specificity at alpha, sequential calibration error, abstention/uncertain rate, and zero-false-positive upper bound.

The low-FPR audit check marked the smoke run as underpowered. It explicitly warns that smoke results cannot support strong low-FPR claims and that sequential repeated decisions require family-wise false-alarm interpretation.

## Reviewer Blockers

Reviewer status remains conservative:

- Publishability assessment: not publishable with fatal blockers.
- Fatal blocker: underpowered low-FPR evidence cannot support pilot/main or publication claims.
- Required fixes include larger honest negative trace counts, explicit pilot/main sample-size gates, prior-work recall, and a related-work matrix.

The v2.1 release gate permits the release because it validates selected idea execution and smoke-path honesty. It does not convert the benchmark scaffold into a finished scientific result.

## What Remains for Pilot/Main

- Power the honest null distribution for target alpha levels.
- Expand collusive scenario diversity.
- Run pilot/main sample sizes under preregistered stopping rules.
- Compare deployable baselines without treating the oracle placeholder as a method.
- Resolve reviewer blockers before claiming publication readiness.
- Keep synthetic limitations prominent unless real deployment evidence is added.
