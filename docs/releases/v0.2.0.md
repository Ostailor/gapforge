# GapForge v0.2.0 Release Notes

GapForge v0.2.0 upgrades the project into a full-text-aware, evidence-located research ideation system with conservative novelty checking. It is still not an exhaustive autonomous literature reviewer.

## What Changed

### Full-Text State and Artifacts

- Added durable models for paper artifacts, paper sections, evidence spans, search query records, source coverage reports, citation edges, and citation graphs.
- Added state persistence for `paper_artifacts.json`, `paper_sections.json`, `evidence_spans.json`, `search_queries.json`, `source_coverage.json`, and `citation_graph.json`.
- Added Markdown artifacts for full-text coverage, evidence spans, and citation graphs.

### PDF Download, Parsing, and Reading

- Added PDF artifact storage under each run directory with safe filenames, SHA256 hashes, duplicate detection, and artifact provenance.
- Added PDF downloader support with cache-aware HTTP, file-size guardrails, PDF validation, `GAPFORGE_DISABLE_NETWORK=1` handling, and non-fatal failure recording.
- Added PDF parsing with page-preserving text extraction, sectionization, common section type classification, and fallback full-text sections.
- Upgraded deep reading to prefer parsed sections, create evidence spans, label abstract-only notes, and avoid unsupported result extraction.

### Evidence, Gaps, and Novelty

- Added locator-backed `EvidenceSpan` support.
- Added gap evidence matrices that capture repeated limitations, missing metrics/datasets, assumptions, counterevidence, and confidence-sensitive evidence rows.
- Added source coverage and full-text coverage reporting.
- Added citation graph construction and conservative related-work expansion.
- Added closest-prior-work novelty dossiers with query plans, candidates considered, top prior work, comparison tables, missing searches, reviewer objections, and recommended actions.
- Added cross-domain transfer candidates with explicit query-only, evidence-found, promoted, and rejected status.

### Human Review and Optional LLM Interfaces

- Added human review commands for approving/rejecting gaps, annotating and marking claims, adding evidence, locking objects, and viewing audit logs.
- Added durable human review audit artifacts.
- Added optional LLM adapter interfaces, deterministic fake client, and prompt-pack generation. Live model calls are not required.

### Reports, Evals, and Tooling

- Upgraded `final_report.md` into a v0.2 evidence-located dossier.
- Added strict report mode, which refuses to recommend a top direction when coverage, evidence, novelty, or reviewer gates are weak.
- Added v0.2 synthetic eval fixtures and metrics for full-text coverage, evidence spans, gap evidence matrices, novelty dossiers, source coverage transparency, human review respect, and report uncertainty.
- Added GitHub Actions CI, pre-commit hooks, coverage tooling, and v0.2 smoke targets.

## How To Run

Install:

```bash
python -m venv .venv
source .venv/bin/activate
make install
```

Offline v0.2 smoke run:

```bash
export GAPFORGE_DISABLE_NETWORK=1
gapforge run "low false positive collusion detection" --v2 --max-papers 8
gapforge report --strict
gapforge coverage
```

Manual local PDF workflow:

```bash
gapforge init-topic "my research topic"
run_id=$(ls -td runs/* | head -1 | xargs basename)
gapforge add-pdf --run-id "$run_id" /path/to/paper.pdf --title "Paper Title" --authors "A. Author;B. Author" --year 2024 --parse
gapforge read --run-id "$run_id" --fulltext-only
gapforge mine-gaps --run-id "$run_id"
gapforge novelty-check --run-id "$run_id" --deep
gapforge report --run-id "$run_id" --strict
```

Network-enabled v0.2 run:

```bash
gapforge run "topic" --v2 --download-pdfs --parse-fulltext --deep-novelty --max-papers 20 --max-expanded-papers 30
```

## What Remains Risky

- v0.2 is deterministic and heuristic. It does not deeply understand papers like a human expert.
- PDF extraction can fail or produce incomplete text.
- Sectionization is approximate and can misclassify headings.
- Source APIs can be incomplete, rate-limited, unavailable, or return sparse metadata.
- Offline fallback records are smoke-test artifacts and must not be cited as real literature.
- Novelty dossiers are stronger than v0.1 lexical checks, but they do not prove novelty.
- Cross-domain transfer candidates are only useful when supported by adjacent-field evidence.

## Known Limitations

- GapForge v0.2 is not an exhaustive autonomous literature reviewer.
- Strict mode is conservative and may refuse to recommend a promising direction if evidence coverage is incomplete.
- Claims still require human verification before research or publication use.
- Synthetic eval fixtures test regression behavior, not real-world research usefulness.
