## Major Features

- Topic portfolios for diverse topic variants before idea generation.
- First-class idea bank with auditable candidates, evidence links, reviews, feedback, reports, and rejected-idea preservation.
- Idea mutation engine with inherited-risk preservation.
- Constructive gap creation for benchmark, measurement, evaluation protocol, dataset, replication, negative-result, theory, system, and tooling paths.
- Cross-domain idea transfer with mechanism, adaptation, breakage, evidence, and search-request separation.
- Codex/GPT-5.4 idea synthesis task packs with strict schemas and validation.
- Active idea search controller and auditable decision policy.
- Idea-specific novelty and counterevidence loop.
- Transparent idea tournament.
- Human preference feedback that can steer search but cannot override evidence gates.
- Research agenda mode for honest no-accepted-idea outcomes.
- Idea yield metrics and v2 release gate.
- v2 idea eval fixtures, dashboard pages, Python API, docs, and Codex-readable skills.
