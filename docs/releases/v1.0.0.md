# GapForge v1.0.0

Status: **stable v1 release documentation prepared**.

GapForge v1.0.0 is the stable evidence-gated research ideation release. It follows the v0.9.1 migration compatibility remediation and the v1 readiness gate pass. It does not tag or publish a package by itself; release actions remain separate operational steps.

## v1 Readiness

`gapforge v1-readiness --write-report --json` passed with no blockers. The v1 gate required:

- v4 Codex workflow gate evidence
- v5 real-literature quality gate evidence
- v6 empirical validation gate evidence
- v7 benchmark/replication gate evidence
- v8 manuscript/submission gate evidence
- v9 pilot accepted as either defensible direction or correct refusal
- Compatibility Audit V2

- artifact hygiene audit
- no unresolved product failures

## Pilot Outcome

The v0.9 external pilot for `low false-positive collusion detection in LLM multi-agent systems` was accepted as a **correct refusal**.

That outcome is valid v1 behavior. GapForge should refuse to recommend a research direction when source coverage, novelty evidence, prior-work review, or empirical support is insufficient. It must not force a research idea to make a workflow appear successful.

## What v1 Can Do

- Run literature campaigns with planned searches, source coverage, canonicalization, prior-work recall, novelty checks, conservative stopping, and human review records.
- Support Codex/GPT-5.4 assisted workflows through task packs, direct runner integration, validated import, attestation, repair, rollback, and campaign review.
- Track claims, evidence, counterevidence, gaps, rejected ideas, and mature research directions across durable run and project state.
- Execute experiments with manifests, run records, result artifacts, parsed metrics, statistical checks, reproducibility records, and failed/negative paths.
- Register benchmarks, manage dataset consent/cache state, run benchmark-like canaries, produce comparison reports, check low-FPR power, and export replication packages.
- Build manuscript and artifact-evaluation packages with traceability, citations/BibTeX, venue checklists, anonymization checks, reviewer simulation, rebuttal plans, and submission package status.
- Run release gates, compatibility audits, artifact hygiene checks, CLI/docs audits, and versioned migrations with backup snapshots.

## What v1 Does Not Claim

- It does not claim GapForge always produces a research idea.
- It does not claim exhaustive autonomous literature review.
- It does not guarantee novelty, correctness, empirical success, benchmark superiority, reproducibility by third parties, publication readiness, venue submission, or venue acceptance.
- It does not treat fake-agent canaries, deterministic fallback records, smoke outputs, or synthetic fixtures as real research evidence.
- It does not trust model-generated citations, claims, results, or reviewer responses without validation and evidence grounding.

## Limitations

- Live sources can be unavailable, rate-limited, stale, incomplete, or fallback-heavy.
- PDF and full-text parsing can miss sections, references, tables, equations, and layout.
- Closest-prior-work and novelty gates reduce risk but cannot prove no relevant paper was missed.
- Experiment and benchmark paths depend on explicit artifacts, datasets, compute, and human review; fixture paths validate plumbing only.
- Manuscript and artifact packages can organize evidence, but they cannot make an incomplete project publishable.
- Reviewer simulation is diagnostic and does not predict acceptance.
- Correct refusal validates honesty for an under-supported topic; it is not a claim of research productivity for every topic.
