GapForge v2.7.0 is conference-candidate hardening infrastructure. It adds the v2.7 checklist, selected-paper hardening commands, issue-level review closure, external-review capture, and a v2.7 release gate. The selected paper is not claimed as `conference_candidate`.

## What Changed

- Added v2.7 roadmap, conference-candidate hardening guidance, and acceptance criteria.
- Added review issue tracking for drastic-review findings, with evidence-linked resolution and fatal-waiver safeguards.
- Added benchmark fit/no-fit hardening, including mapped real benchmark candidates, no-fit argument generation, and manuscript insertion text.
- Added selected-benchmark ablation planning, synthetic run labeling, missing-ablation blockers, and ablation reports for the required v2.7 dimensions.
- Added top-conference manuscript revision/readiness commands that preserve claim traceability and limitations.
- Added external expert review capture/reporting with human and simulated sources kept separate.
- Added the v2.7 release gate and v2.7 eval fixtures for conference, workshop, revise, and no-go paths.
