## Baseline Status

Required baselines were calibrated and run for the pilot release gate. The suite includes random, threshold/frequency, repeated-action, lexical, statistical anomaly, sequential change-point, calibrated threshold, transcript-visible heuristic, and action-only heuristic monitors.

Some calibration records warn when observed calibration FPR exceeds the target alpha for a monitor/threshold. The baseline reviewer therefore blocks strong scientific comparison claims even though the release gate can pass as pilot maturity.
