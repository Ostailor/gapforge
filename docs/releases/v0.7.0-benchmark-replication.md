## Real Benchmark Canary

- Profile: `local_public_small_benchmark`
- Dataset: UCI Iris public small dataset
- Dataset handling: explicit consent plus cache-managed download
- Task: binary detection, treating Iris virginica as the positive class
- Baseline: always-negative heuristic detector
- Proposed detector: petal-width threshold detector
- Metric: false positive rate with confidence interval
- Run type: `main` for the benchmark canary workspace
- Status: passed

This canary validates that GapForge can execute a real/local public benchmark path with consent, results, comparison, error analysis, and replication packaging. It is not a broad benchmark suite, not a GPU/cluster validation, and not an SOTA result.

## Safety Rules Preserved

- Fixture canaries do not count as real benchmark validation.
- No downloaded dataset is committed by default.
- No fake benchmark result is accepted.
- Smoke and main results stay labeled separately.
- Failed benchmark jobs remain visible.
- Missing baselines and unverified leaderboards block strong claims.
- No SOTA claim is made without verified leaderboard evidence and policy support.

## Remaining Risks and Not Tested

- No large public benchmark suite was run.
- No restricted/gated dataset workflow was completed.
- No GPU, Docker, Slurm, cluster, or multi-machine run was validated as available.
- No independent third-party reproduction was completed.
- The small UCI Iris canary validates workflow mechanics and artifact discipline, not real research impact.
