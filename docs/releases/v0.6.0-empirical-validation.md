## Result Labels Required by v0.6

- **Planned experiment**: protocol or scaffold exists, but no run record/result artifact exists.
- **Smoke run**: wiring execution only; not empirical success.
- **Pilot result**: executed exploratory result with artifacts, not necessarily final evidence.
- **Main result**: executed primary result with artifacts, statistical analysis, and reproducibility checks.
- **Failed result**: failed execution is preserved with logs and failure reason.
- **Hypothetical expected result**: forecast or expectation; never treated as observed evidence.
- **Real result**: requires run record, result artifact, parsing, analysis, and appropriate review.

## Blocking Rules

GapForge v0.6 must not:

- create empirical claims without result artifacts
- hide failed or negative runs
- label smoke output as real empirical success
- include a `Results` section with unsupported claims
- accept fake result metrics from Codex or fixtures
- mark paper-ready export when reproducibility or empirical review gates fail
